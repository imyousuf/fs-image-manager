# Shared Contracts — fs-image-manager team

**Owner:** backend-platform (lands these first). **Audience:** all teammates.
This is the single source of truth for the seams between teammates. If you need to change a
contract, the change goes through backend-platform + the lead, not unilaterally. Reference
`docs/TECH_SPEC.md` for the full design rationale.

---

## 0. Module & toolchain
- Module path stays `github.com/imyousuf/fs-image-manager`. `go 1.24` (needs `os.Root`).
- **CGO-free**: pure-Go only in the binary. External *runtime* tools (ffmpeg, ffprobe,
  dcraw, exiftool, darktable-cli, ollama, aws) are detected at runtime and optional.
- Routing: stdlib `net/http` `ServeMux` (1.22+ method+pattern syntax). No gorilla/mux.
- DB driver: `modernc.org/sqlite` (pure Go). Data access: **sqlc**. Migrations: **goose**
  (`github.com/pressly/goose/v3`) with embedded SQL.
- Lint: `golangci-lint` (repo-root `.golangci.yml`: standard set, **errcheck strict
  module-wide incl. `_test.go`** — no per-path relaxation; pinned v2.11.3). Ignore an
  intentional error with `_ = x.Err()`; for deferred closes use
  `defer func() { _ = x.Close() }()`, never a bare `defer x.Close()`. Format: `gofmt -s`.
  Tests: `go test -race ./...`.

## 2. The alias-prefixed media path (CRITICAL)
- A **`MediaPath`** is a string of the form `<alias>/<relpath>` — e.g.
  `pictures/2021/IMG_1234.CR3`. The first segment is the library **alias**; the rest is the
  path **inside** that library root.
- **Relative paths are NOT supported.** No leading `/`, no `.`/`..` segments, no
  alias-less paths. Validation rejects them.
- `internal/mediapath` (platform) provides the only sanctioned resolver:
  ```go
  type Resolver interface {
      // Resolve maps "<alias>/<relpath>" to an absolute on-disk path, guaranteed to be
      // inside the alias's configured root. Returns error on unknown alias, relative
      // path, or any traversal escape (verified via filepath.Clean + os.Root).
      Resolve(mp MediaPath) (absPath string, lib Library, rel string, err error)
      Libraries() []Library          // configured roots, in config order
      Open(mp MediaPath) (*os.File, error)   // traversal-proof open via os.Root
  }
  ```
- **Nobody constructs on-disk paths by string concatenation.** All filesystem access for
  library media goes through this resolver. This is the path-traversal fix.

## 3. Shared Go types (package `internal/catalog`; type SHAPES owned by backend-platform in types.go, repo behaviour by media-pipeline in repo*.go)
```go
type Library struct { Alias, Name, Root string }   // Root is the absolute dir

type FileKind string // "jpg","png","raw","video","sidecar","other"

type File struct {
    MediaPath MediaPath  // alias/relpath
    Kind      FileKind
    Size      int64
    ModTime   time.Time
    Hash      string     // content hash (xxhash/sha256 of head+size; see media spec)
}

type Asset struct {           // one logical photo/video (may bundle RAW+JPG+sidecars)
    ID        string          // stable: hash of "<alias>/<dir>/<basename-without-ext>"
    Alias     string
    Dir       string          // relpath of containing dir
    BaseName  string          // filename without extension
    Kind      string          // "image" | "video"
    Files     []File          // members (e.g. .CR3 + .JPG + .XMP)
    DisplayPath MediaPath      // the file used for thumbnails/preview (JPG if present)
    CapturedAt *time.Time      // from metadata (search-index fills)
}

type Derivative struct {       // cached transform output
    AssetID string
    Kind    string             // "thumb","poster","preview","webp","mp4","developed-jpg"
    Params  string             // e.g. "w=320"
    Path    string             // absolute path in the cache dir
    Mime    string
}

type Person struct { ID, Name, CoverFaceID string }
type Face struct {
    ID, AssetID string
    BBox        [4]float64     // x,y,w,h normalized
    PersonID    string         // "" = unknown
    Confidence  float64
    ExtRef      string         // Rekognition FaceId or local vector ref
}
```
Sidecar rule: `.xmp/.pp3/.thm` and other non-media attach to the asset as `File`s with
`Kind=="sidecar"`; they never form their own asset.

## 4. Core interfaces (declared in `internal/catalog`, implemented by their owners)
**These shared "ports" and their result structs live in `internal/catalog`**
(`ports.go` for the interfaces, `types.go` for `Job`/`JobResult`/`EnrichResult`),
NOT in the owning feature packages. This is deliberate: it lets a producer
depend on `catalog.Queue` while a different package implements it, with no
import cycle (e.g. media-pipeline enqueues via `catalog.Queue`; jobs-worker's
`internal/jobs` *implements* `catalog.Queue` — neither imports the other).
The signatures are owned by backend-platform (changes funnel through it + the
lead); the *implementations* are owned by the packages noted below.
```go
// catalog.Cache — implemented by internal/cache (media-pipeline)
type Cache interface {
    Get(key string) (path string, ok bool)
    Put(key string, r io.Reader, mime string) (path string, err error)
    Key(assetID, kind, params, srcHash string) string
}

// catalog.Job / catalog.JobResult / catalog.Queue
//   — Queue implemented by internal/jobs (jobs-worker); producers hold a
//     catalog.Queue and may treat a nil Queue as "no worker configured".
type Job struct { ID, Kind string; AssetID string; MediaPath MediaPath; Params map[string]string; Status string }
type Queue interface {
    Enqueue(ctx, kind string, assetID string, mp MediaPath, params map[string]string) (Job, error)
    Claim(ctx, kinds []string, lease time.Duration, n int) ([]Job, error)
    Complete(ctx, id string, result JobResult) error
    Fail(ctx, id, reason string) error
}
type JobResult struct { DerivativeKind, Mime string; Bytes []byte; Data map[string]any }

// catalog.Enricher / catalog.EnrichResult — implemented by internal/enrich (ai-people)
type Enricher interface { Enrich(ctx, mp MediaPath, r io.Reader) (EnrichResult, error) }
type EnrichResult struct { Labels []string; Caption, OCRText string; Embedding []float32 }

// catalog.FaceRecognizer — implemented by internal/people (ai-people)
type FaceRecognizer interface {
    DetectAndEmbed(ctx, r io.Reader) ([]Face, error)
    Match(ctx, f Face) (personID string, confidence float64, err error)
}
```
Job kinds (constants in catalog): `transcode-video`, `develop-raw`,
`convert-image`, `enrich-ai`, `face-index`. `internal/internaltest` ships
`Fake{Cache,Queue,Enricher,FaceRecognizer}` that implement these directly.

## 5. HTTP API (serve) — public, consumed by frontend
JSON unless noted. Auth: `Authorization: Bearer <token>` if `[auth] token` is set, else open.
Error envelope: `{"error":{"code":string,"message":string}}` with proper status.

- `GET  /api/libraries` → `[{alias,name}]`
- `GET  /api/assets?path=<alias>/<dir>&cursor=&limit=` → `{items:[AssetView], next:cursor}`
  (folder browse; `path` may be just `<alias>` for a root). AssetView:
  `{id,alias,name,kind,displayThumb:url,preview:url,stream:url,download:url,files:[{mediaPath,kind,size}],capturedAt}`
- `GET  /api/assets/search?q=&from=&to=&alias=&camera=&person=&cursor=&limit=` → same shape
- `GET  /api/assets/timeline?alias=&from=&to=` → `[{date,count}]`
- `GET  /api/assets/{id}/thumb?size=320` → image bytes (cached; ETag)
- `GET  /api/assets/{id}/preview` → display-size image bytes (cached; ETag)
- `GET  /api/assets/{id}/stream` → original/transcoded bytes, **supports `Range`**
- `GET  /api/assets/{id}/download?variant=jpg|raw|both|video` → file or zip
- `POST /api/download` body `{paths:[MediaPath]}` → zip (each path validated)
- `POST /api/upload?alias=<alias>&dir=<relpath>` multipart → stores file, triggers ingest
- `GET  /api/people` → `[Person]` ; `GET /api/people/{id}/assets` ; `POST /api/people/{id}` `{name}`
All `path`/`mediaPath` inputs validated via `internal/mediapath`. IDs are asset IDs (§3).

## 6. DB / migrations / sqlc convention
- Migrations: `internal/db/migrations/NNNN_desc.sql` (goose format, embedded via
  `//go:embed`). **Per-role number ranges to avoid collisions:** platform `0001–0099`,
  media-pipeline `0100–0199`, search-index `0200–0299`, jobs-worker `0300–0399`,
  ai-people `0400–0499`.
- Queries: `internal/db/queries/<domain>.sql` (one file per domain you own).
- `sqlc.yaml` at repo root (platform owns) generates `internal/db/store`. After editing
  your queries/migrations, run `sqlc generate`; commit regenerated store; the lead resolves
  any regen conflicts. Don't hand-edit `internal/db/store`.
- FTS5 (search-index) and vector storage (ai-people) are plain migrations/tables.

## 9. Conventions
- Errors: wrap with `%w`; HTTP layer maps to the error envelope.
- Logging: `log/slog`, structured; request logging middleware in `internal/server`.
- Context-first signatures; respect cancellation.
- Tests live beside code (`*_test.go`); shared fixtures in `internal/internaltest`
  (platform provides: temp dirs, sample media copier from `~/Pictures`/`~/Videos`, fakes
  for Cache/Queue/Enricher/FaceRecognizer). Real external-tool/AWS tests are
  `//go:build integration` tagged.
